# 班级成员管理系统 · 用户手册

> 适用对象：班长（唯一操作者）  
> 系统形态：浏览器网页（本机使用）  
> 默认地址：`http://127.0.0.1:8080`

---

## 1. 这个系统是做什么的？

帮你**自动核对班级名单**，替代人工一条条对。

典型场景：

- 讲座抽签后，快速找出**没抽中 / 没参加**的人  
- 活动报名、志愿活动后，统计**谁还没报名**  
- 作业、回执、青年大学习，查**谁没交 / 没打卡**  
- 从第三方小程序导出名单后，一键和本班名单比对  

系统**只做筛查、统计、记录、导出**，不做抽签、报名、签到本身。

## 2. 如何启动系统

### 2.1 方式一：直接用（已启动时）

1. 确认后端已在运行（IDEA 里跑过 `ClassMemberApplication`，或已有 jar 在跑）  
2. 浏览器打开：`http://127.0.0.1:8080`  
3. 左侧可切换各功能页  

检查是否已启动：浏览器访问 `http://127.0.0.1:8080/api/health`，看到 `"status":"UP"` 即正常。

### 2.2 方式二：在 IntelliJ IDEA 中启动

1. 打开工程 `mimo_Class_Management_System`  
2. 打开文件：`backend/src/main/java/com/classmgmt/ClassMemberApplication.java`  
3. 点击 `main` 方法左侧绿色三角 ▶（或右键 → Run）  
4. 控制台出现 Tomcat / Started 字样后，访问 `http://127.0.0.1:8080`  

若提示 **8080 端口被占用**：先结束占用进程，或改配置里的端口后再启动。

### 2.3 方式三：开发模式（改前端时）

```text
# 终端 1：后端（IDEA 或命令行）
# 终端 2：前端
cd frontend
npm.cmd run dev
```

浏览器打开：`http://127.0.0.1:5173`（页面会自动请求后端 8080）。

### 2.4 访问口令（可选）

默认**无需登录**。

若管理员在配置里设置了 `app.access-password`，页面**右上角**会用到口令框：

1. 在右上角输入口令  
2. 离开输入框或确认后自动保存到本机  
3. 之后请求会自动带上口令  

若提示「访问口令错误或未提供」，检查右上角是否填错。

> 默认服务只监听本机 `127.0.0.1`，同局域网其他设备一般访问不到，有利于保护班级数据。

## 3. 功能总览

| 菜单 | 作用 |
|------|------|
| **名单筛查** | 粘贴名单，一键比对，查看三栏结果 |
| **基准名单** | 维护本班花名册（系统比对的唯一标准） |
| **历史记录** | 查看/改名/备注/导出/删除过去的核对 |
| **长期任务** | 青年大学习等「按期反复核对」的任务 |
| **自定义分组** | 卫生组、学习组等；可按组看未参与 |

## 4. 第一步：设置基准名单（先做这个）

所有筛查都以**基准名单**为准。名单不对，结果就不对。

### 4.1 查看当前名单

1. 左侧点 **「基准名单」**  
2. 顶部显示：**已锁定 / 未锁定**、当前人数  
3. 表格中是全部学生姓名（可附学号）  

首次启动若库为空，系统会写入 **36 人示例名单**，方便你先熟悉流程。

### 4.2 用真实名单替换（推荐流程）

#### 方式 A：文件导入（推荐）

1. 若显示 **「已锁定」**，先点 **「解锁修改」**  
2. 在导入区 **直接拖入** 文件/图片（虚线框），或点击该区域选择文件  
3. 支持格式：  
   - `.txt`：一行一个姓名  
   - `.csv`：如 `学号,姓名` 或 `姓名,学号`  
   - `.xlsx` / `.xls`：Excel，自动取有效列，忽略表头「姓名/学号」等  
   - **`.jpg` / `.png` 等图片**：对花名册/表格截图做 **OCR 文字识别**，自动抽出学号与姓名  
4. 系统解析后弹出 **导入预览**（人数、姓名、学号）  
5. 选择 **「追加到列表」** 或 **「覆盖列表」**  
6. 核对表格 → 点 **「保存名单」** → **「锁定名单」**  

> 图片识别建议：优先使用 **白底黑字** 的表格截图；系统会先用 **Windows 系统 OCR**（中文更好），失败再回退 Tesseract。识别结果务必在预览里核对，个别字可能认错或漏行（可手动补全后再保存）。

可点 **「下载导入模板」** 获取示例文件格式。

#### 方式 B：粘贴导入

1. 解锁后，在「批量粘贴」框粘贴名单（一行一个，或逗号/顿号分隔）  
2. 点 **「解析并覆盖」** 或 **「解析并追加」**  
3. 核对后 **「保存名单」** → **「锁定名单」**  

列表支持 **按姓名/学号搜索**；保存时若存在 **重名** 会提示，建议补全学号。

### 4.3 锁定说明

| 状态 | 含义 |
|------|------|
| **未锁定** | 可以改名单 |
| **已锁定** | 不能改名单；筛查照常可用 |

- 修改名单后，**之后**的筛查用新名单  
- **历史记录**里已保存的结果**不会**被改写（当时的快照）  
- 整表替换名单后，原「分组成员」会清空，请重新到分组页配置

## 5. 核心功能：名单筛查

这是日常用得最多的功能。

### 5.1 标准操作步骤

1. 左侧点 **「名单筛查」**  
2. 把名单 **拖进**「拖到这里」区域，或粘贴到大文本框（也支持点击选择文件/图片）  
3. 可选：填写 **任务名称**（如「9月20日讲座抽签」）  
4. 可选：选择关联的 **长期任务**  
5. 勾选 **「保存为历史记录」**（建议勾选，方便以后查）  
6. 点 **「一键筛查」**  
7. 下方立即显示统计和三栏名单  

### 5.2 结果怎么看？

| 栏目 | 含义 | 你通常怎么做 |
|------|------|----------------|
| **已参与** | 名单里出现的本班同学 | 可忽略，或作已完成名单 |
| **未参与** | 在基准名单里、但粘贴名单中没有的人 | 点名提醒、催交通知 |
| **无效/异常** | 不在本班的姓名、乱码、无法识别内容 | 检查粘贴源是否贴全、贴错 |
| **重复姓名** | 同一人在粘贴名单里出现多次 | 系统已去重，仅作提示 |

顶部数字对应各栏人数，例如：

- 基准人数 36  
- 已参与 30  
- 未参与 6  
- 无效 0  
- 重复 1  

### 5.3 粘贴时系统会自动处理什么？

- 行首序号：`1. 张三`、`2、李四` → 自动去掉序号  
- 全角/半角、多余空格  
- 逗号、顿号、分号、换行、制表符等分隔  
- 同一人重复出现 → 只算一次  
- 不在本班的内容 → 进入「无效/异常」，**不会**算成已参与  

### 5.4 匹配规则（重要）

- 按 **姓名全称精确匹配**  
- 若名单里填了学号，且粘贴内容正好是该**学号全称**，也可匹配到人  
- **不会**做模糊纠错：例如班里是「张三」，粘贴「张三丰」**不会**算成张三，会进无效栏  

请尽量保证粘贴的姓名与基准名单一致。

### 5.5 结果怎么用？

| 操作 | 说明 |
|------|------|
| **复制未参与名单** | 一键复制，可直接贴进班群 |
| **导出Excel** | `.xlsx`，含三类名单与人数，方便打印/转发 |
| **导出CSV** | 纯文本表格，方便再加工 |
| **一键清空** | 清空粘贴框与本次结果，恢复空白页面，方便开始下一轮核对（已保存的历史不受影响） |

勾选了「保存为历史记录」时，导出按钮才可用（需要先有记录 ID）。

### 5.6 示例

基准名单含：王伟、李娜、张敏 …（共 36 人）

粘贴：

```text
1. 王伟
2、李娜
李娜
外校同学
```

结果大致为：

- 已参与：王伟、李娜（2 人）  
- 未参与：其余 34 人  
- 无效：外校同学（1 条）  
- 重复：李娜（1 人）

## 6. 历史记录

### 6.1 能做什么

- 按 **任务名称** 搜索  
- 按 **长期任务** 筛选  
- **查看**某次核对的完整三栏结果  
- **改名 / 改备注**（不改名单结果）  
- **导出** Excel / CSV  
- **删除**无用记录（需确认）  

### 6.2 注意

- 人员名单是**当时快照**，不能在历史里手改已参与/未参与  
- 若需重新核对，请回到「名单筛查」再跑一次（会生成新记录）  
- 只允许改 **任务名称** 和 **备注**  

操作：历史记录列表 → 对应行 → **「改名/备注」** → 修改 → 保存。

## 7. 长期任务（按期统计）

适合：青年大学习、德育打卡、每周材料提交等。

### 7.1 使用步骤

1. 左侧 **「长期任务」** → **「新建任务」**  
2. 填写名称，如「青年大学习」，类型可写「学习」，备注随意  
3. 保存  
4. 每一期结束后：  
   - 打开 **「名单筛查」**  
   - 粘贴本期提交名单  
   - 任务名称写清楚，如「青年大学习第3期」  
   - **关联长期任务** 选「青年大学习」  
   - 勾选保存 → 一键筛查  
5. 回到「长期任务」→ 该任务行 → **「查看各期」**，可浏览每期已参与/未参与人数  

删除长期任务时，**历史核对记录仍会保留**（只是不再挂在该任务下）。

## 8. 自定义分组

适合：卫生小组、值日组、学习小组、活动小组。

### 8.1 创建分组

1. 左侧 **「自定义分组」** → **「新建分组」**  
2. 填写分组名称、备注  
3. 在「成员」中从基准名单多选学生  
4. 保存  

### 8.2 按分组查看核对结果

1. 先在「名单筛查」中完成一次核对并**保存历史记录**  
2. 打开 **「自定义分组」**  
3. 点 **「按分组筛查」**（工具栏或某一行的按钮）  
4. 选择 **分组** 和 **历史记录**  
5. 点 **「查看该组结果」**  
6. 页面显示：  
   - 组内已参与  
   - 组内未参与（方便只催某一组）  

修改基准名单（整表替换）后，请重新配置各组成员。

## 9. 数据备份与恢复

系统数据保存在本机 MySQL 数据库 `class_mgmt` 中。

### 9.1 建议备份时机

- 大量录入真实名单之后  
- 学期末复盘之前  
- 换电脑 / 重装系统之前  

### 9.2 如何备份（接口方式）

浏览器或工具访问：

```text
GET http://127.0.0.1:8080/api/backup/export
```

会返回 JSON（含学生、分组、任务、核对记录等），可另存为文件妥善保存。

### 9.3 如何恢复

```text
POST http://127.0.0.1:8080/api/backup/import
Content-Type: application/json
```

请求体为备份 JSON 原文。成功后返回各表数量。

> 日常班长使用以页面功能为主；备份接口供维护、迁移时使用。若需在界面上一键备份，可作为后续增强。

### 9.4 用 Navicat 查看数据

1. 打开 Navicat 15 → 连接本机 MySQL  
2. 数据库选择 `class_mgmt`  
3. 常用表：  
   - `student`：基准名单  
   - `check_record`：历史核对  
   - `long_task`：长期任务  
   - `task_group` / `group_member`：分组  
   - `system_setting`：是否锁定等  

在 Navicat 里改数据需谨慎，优先在系统页面操作。

## 10. 常见问题

### Q1：打开网页显示无法访问？

- 后端是否已启动（IDEA 控制台是否在运行）  
- 地址是否为 `http://127.0.0.1:8080`（不要写成 https）  
- 是否被占用 8080：先停掉旧进程再在 IDEA 启动  

### Q2：一键筛查后「未参与」人数不对？

- 先看 **基准名单** 人数与姓名是否正确  
- 看「无效/异常」里是否误贴了本班同学（姓名写错、多字少字）  
- 确认粘贴名单是否完整、是否只贴了一部分  

### Q3：提示名单已锁定，无法保存？

- 点 **「解锁修改」** → 确认 → 修改 → 保存 → 再 **「锁定」**  

### Q4：历史记录里改不了未参与名单？

- 这是**设计如此**：历史是快照，保证复盘可信  
- 需要新结果请重新在「名单筛查」执行一次  

### Q5：手机能不能用？

- 系统是网页，**电脑浏览器**为主要使用方式  
- 默认只监听本机；若要在手机访问，需修改服务监听地址并配置访问口令（需一定技术操作）  
- 界面已做一定自适应，手机浏览器可查看，但操作电脑更方便  

### Q6：数据会不会上传到外网？

- 默认数据只存在你的电脑和本机 MySQL 中  
- 服务默认绑定 `127.0.0.1`，不对外网开放  

### Q7：忘记要催谁了？

- 打开 **「历史记录」** → 找到那次任务 → **查看** → 看「未参与」  
- 或 **导出 / 复制** 未参与名单

## 11. 推荐日常操作流程（速查）

```text
【一次性】
启动系统 → 基准名单 → 解锁 → 粘贴真实名单 → 保存 → 锁定
（可选）创建长期任务、创建分组

【每次核对】
第三方工具导出/复制名单
    → 名单筛查 → 粘贴 → 填任务名 → 关联长期任务（如有）
    → 勾选保存 → 一键筛查
    → 看「未参与」→ 复制或导出 → 班群通知
    →（可选）分组页 → 按分组查看某组未参与

【周期末】
历史记录 → 按任务汇总
长期任务 → 查看各期
（可选）备份接口导出 JSON
```
